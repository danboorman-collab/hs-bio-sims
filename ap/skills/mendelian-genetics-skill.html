Does the data fit?

Expected counts, chi-square, degrees of freedom, and the verdict.

Two flies heterozygous for both genes were crossed. If the two genes are on different chromosomes and each has one dominant allele, the model predicts four phenotype classes in the ratio 9 : 3 : 3 : 1.

The counts never come out exactly 9 : 3 : 3 : 1. Chi-square puts one number on the gap, and the table says whether a gap that size is more than chance.

Step 1 — the expected count for the commonest class

An expected count is the share the model predicts, taken of the total counted. It is not rounded to a whole fly: it is what the model predicts, not a count.

Why this step: Chi-square compares what was counted with what the model predicts, so the prediction has to be turned into numbers of flies first. Without the expected counts there is nothing to compare the observed ones against.

Step 2 — and for the rarest class

Why this step: The rarest class matters most to the test. Chi-square divides each class's gap by that class's own expected count, so a small expected count makes a given gap count for more. This is also why several hundred offspring are counted rather than a few dozen.

Step 3 — one class's contribution to chi-square

Chi-square takes each class in turn: the observed count minus the expected count, squared, then divided by that class's own expected count. The squaring makes a shortfall count the same as an excess of the same size.

Why this step: Chi-square is built one class at a time. Each class contributes an amount that grows with how far it strayed and shrinks with how many were expected there. Working one class by hand shows where the total comes from.

χ² = Σ (o − e)² ÷ e

Step 5 — degrees of freedom

Once the total and all but one of the counts are fixed, the last count is fixed too. The number of classes free to vary is the degrees of freedom: the number of classes minus one. It counts classes, never offspring.

Why this step: The table needs to know how many ways the counts were free to vary, because a gap of a given size means less when there were more classes for it to appear in. Once the total and all but one class are fixed, the last class is fixed too.

Why this step: This is the number chi-square has to beat before the model is rejected. It comes out of a table, not out of the data: it is how large a gap chance alone would produce in more than 5 batches in 100.

Step 8 — what the verdict means

What does failing to reject tell the breeder about the 9 : 3 : 3 : 1 model?

χ² = 1.51, below the critical value of 7.81 at 3 degrees of freedom. Fail to reject the null hypothesis. The 640 flies are consistent with a 9 : 3 : 3 : 1 ratio, and so with two genes assorting independently. That is not the same as proving it.
